# Output schema

The exact JSON keys each command's success and error results contain. Generated by running
every `bin/*` command against real fixtures and reading back what they printed, not by reading
the source — if this document and the code disagree, the code changed and this document is
stale.

## Success envelope

Every command's success result is a flat JSON object on stdout. Two keys are present on every
command and never change shape:

| Key | Type | Meaning |
|---|---|---|
| `status` | string | Always `"ok"`. |
| `command` | string | The command name, e.g. `"inspect"`, `"ingest-vector"`. |

All other keys are command-specific and listed below. Existing key names are a stable
compatibility surface: they are never renamed, only added to.

## Error envelope

A failure prints one JSON object to stderr and exits non-zero (1 for a handled `GisError`, 2 for
a Typer usage error such as a missing required option). See `llm_gis/errors.py`.

| Key | Type | Meaning |
|---|---|---|
| `status` | string | Always `"error"`. |
| `code` | string | One of the error codes below. |
| `message` | string | What went wrong, human-readable. |
| `suggested_action` | string | What the caller should try next. |
| `details` | object | Optional. Present when there is structured context, e.g. `command`, `returncode`, `stderr`, `stdout` for a failed subprocess. |

Error codes (`llm_gis/errors.py`):

| Code | Raised when |
|---|---|
| `INPUT_NOT_FOUND` | A required input path does not exist. |
| `CRS_MISSING` | `inspect` found no CRS and ingestion was attempted without `--src-crs`. |
| `CRS_SUSPICIOUS` | `inspect` flagged the CRS as implausible for the data's extent and no `--src-crs` was given. |
| `UNSUPPORTED_FORMAT` | `inspect` could not read the file as vector or raster, or `export --format` is neither `gpkg` nor `geojson`. |
| `COMMAND_FAILED` | A wrapped subprocess (`ogr2ogr`, `gdalwarp`, `psql`, ...) exited non-zero. |
| `PATH_OUTSIDE_ROOT` | A path meant to be under `/data/incoming` resolves outside it. |
| `TABLE_NOT_FOUND` | `describe-table` was given a schema.table that does not exist (or is invisible to the connecting role). |
| `MISSING_ARGUMENT` | `export` was called with neither `--table` nor `--sql`. |
| `UNEXPECTED` | Anything else — an unhandled exception, rendered as JSON instead of a traceback. |

## Commands

### `bin/stage`

| Key | Type | Meaning |
|---|---|---|
| `ingest_id` | string | The id assigned to this input, `YYYYMMDDHHMMSS_<hash10>` unless `--ingest-id` was given. |
| `input_path` | string | The path staged, as given. |
| `input_hash` | string | SHA-256 of the input file (or of its directory contents, if a directory). |
| `staging_dir` | string | `/data/work/staging/<ingest_id>/`. |
| `staged_item` | string | Path to the copy (or extracted zip) inside `staging_dir`. |
| `created_at` | string | UTC timestamp. |

### `bin/inspect`

Vector result:

| Key | Type | Meaning |
|---|---|---|
| `dataset_kind` | string | `"vector"`. |
| `input_path` | string | The path inspected. |
| `layers` | array | One entry per layer: `{name, geometry_type, feature_count}`. |
| `detected_crs` | string \| null | `AUTHORITY:CODE` where resolvable, else WKT, else null. |
| `extent` | object \| null | `{minx, miny, maxx, maxy}` across all layers. |
| `crs_status` | string | `"ok"`, `"missing"`, or `"suspicious"`. |
| `crs_reasons` | array of string | Why `crs_status` is not `"ok"`; empty when it is. |
| `raw` | object | The full `ogrinfo -json` output, for anything not summarised above. |
| `created_at` | string | UTC timestamp. |

Raster result: same shape, with `dataset_kind: "raster"`, `size` (`[width, height]`) and `bands`
(`[{band, type, nodata}, ...]`) instead of `layers`, and `raw` holding the full `gdalinfo -json`
output.

### `bin/ingest-vector`

| Key | Type | Meaning |
|---|---|---|
| `ingest_id` | string | The ingest id used (resolved or given). |
| `input_path` | string | The path ingested. |
| `input_hash` | string | SHA-256 of the input. |
| `dataset_kind` | string | `"vector"`. |
| `schema` | string | Destination schema, `raw_<ingest_id>` unless `--schema` was given. |
| `table` | string | Destination table name. |
| `detected_crs` | string \| null | CRS `inspect` found before any override. |
| `chosen_crs` | string \| null | CRS actually used: `--dst-crs`, else `--src-crs`, else `detected_crs`. |
| `crs_status` | string | `"ok"`, `"missing"`, or `"suspicious"`, from the pre-ingest inspect. |
| `feature_count` | integer | Rows in the created table after load. |
| `invalid_before` | integer | Geometries that failed `ST_IsValid` before `ST_MakeValid` was applied. |
| `invalid_after` | integer | Geometries still invalid after `ST_MakeValid` (should be 0). |
| `created_at` | string | UTC timestamp. |

### `bin/ingest-raster`

| Key | Type | Meaning |
|---|---|---|
| `ingest_id` | string | The ingest id used. |
| `input_path` | string | The path ingested. |
| `input_hash` | string | SHA-256 of the input. |
| `dataset_kind` | string | `"raster"`. |
| `schema` | string | Destination schema. |
| `table` | string | Destination table name. |
| `detected_crs` | string \| null | CRS `inspect` found before any override. |
| `chosen_crs` | string \| null | CRS actually used: `--dst-crs`, else `--src-crs`, else `detected_crs`. |
| `crs_status` | string | `"ok"`, `"missing"`, or `"suspicious"`. |
| `band_count` | integer | Bands in the raster actually handed to `raster2pgsql` (post-warp if `--dst-crs` was given). |
| `size` | array of integer \| null | `[width, height]` in pixels of that same raster. |
| `created_at` | string | UTC timestamp. |

### `bin/run-sql`

| Key | Type | Meaning |
|---|---|---|
| `ingest_id` | string | The (sanitized) ingest id used for `search_path`. |
| `sql_path` | string | The SQL file executed. |
| `log_file` | string | Where `psql`'s combined output was written. |
| `schema` | string | `analysis_<ingest_id>`, the schema inspected for the next field. |
| `tables` | array | Every table in `schema` after execution: `{table, row_count}`. Empty if the schema does not exist — never an error. |
| `executed_at` | string | UTC timestamp. |

### `bin/export`

| Key | Type | Meaning |
|---|---|---|
| `output_path` | string | The file written. |
| `output_format` | string | `"gpkg"` or `"geojson"`. |
| `table` | string \| null | The table exported, if `--table` was used. |
| `sql` | string \| null | The query exported, if `--sql` was used. |
| `feature_count` | integer \| null | Features in the file just written, read back with `ogrinfo -json -ro`. |
| `crs` | string \| null | CRS of the file just written, read back the same way. |

### `bin/doctor`

| Key | Type | Meaning |
|---|---|---|
| `created_at` | string | UTC timestamp. |
| `versions` | object | `{gdal, psql}` version strings. |
| `database_ok` | boolean | Whether `SELECT 1` succeeded. |
| `database_error` | string \| null | The error if it did not. |
| `paths` | object | `{incoming_exists, outgoing_exists, work_exists}` booleans. |
| `pg_env` | object | `{PGHOST, PGPORT, PGDATABASE, PGUSER}` as seen by the process (never the password). |

### `bin/list-ingestions`

| Key | Type | Meaning |
|---|---|---|
| `ingestions` | array | Newest first: `{ingest_id, input_path, detected_crs, chosen_crs, status, created_at, updated_at}`. |
| `count` | integer | Length of `ingestions`. |
| `queried_at` | string | UTC timestamp. |

### `bin/describe-table`

| Key | Type | Meaning |
|---|---|---|
| `schema` | string | Schema queried. |
| `table` | string | Table queried. |
| `columns` | array | `{column_name, data_type, is_nullable, column_default}` in ordinal order. |
| `row_count` | integer | `SELECT COUNT(*)` on the table. |
| `queried_at` | string | UTC timestamp. |

## A note on cost

`run-sql`'s `tables` field lists the schema's tables before and after the SQL runs and counts
rows only in the ones the run added. Cost scales with what the SQL created, not with what the
schema already held, so a schema accumulating large intermediates is not rescanned on every
call. A run that only modifies existing tables therefore reports an empty list.
