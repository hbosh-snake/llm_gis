# Pre-event Vegetation Specification Rewrite Design

The rewritten specification will retain the purpose, input-selection criteria, methodology, and deliverables of the original request. FKB-AR5 will be defined as the primary thematic and semantic reference rather than necessarily the production data source. The required output detail will be bounded by what the selected satellite imagery can reliably support, with all additional classes related hierarchically to FKB-AR5 and documented.

The deliverable will be a new plain-text file under a dated project folder in `data/outgoing/`; the original incoming specification will remain unchanged.
